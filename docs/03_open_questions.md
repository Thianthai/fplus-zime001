# 03 — ทะเบียนข้อสงสัย

| # | เรื่อง | ใครตอบ | สถานะ |
|---|---|---|---|
| Q-01 | **`YY` ต้องเท่ากับปีปัจจุบัน หรือเป็นเลขอะไรก็ได้ 00-99** — ถ้าต้องเท่าปีปัจจุบัน ใช้วันที่ไหน (system date UTC หรือ timezone ของ user/plant) และช่วงข้ามปีต้องยอมปีก่อนหรือไม่ | ผู้ใช้ | ⬜ |
| Q-02 | **`DD` เช็คแค่ 01-31 หรือต้องเป็นวันที่มีจริง** (เช่น 260231 / 250229 ต้องไม่ผ่าน) | ผู้ใช้ | ⬜ |
| Q-03 | **ค่าที่สั้นกว่า 10 หรือมีช่องว่าง** — `batch_in` เป็น CHAR 10 ค่าสั้นจะมีช่องว่างท้าย ถือว่าไม่ผ่าน (ตามข้อ 4.1) ใช่หรือไม่ | ผู้ใช้ | ⬜ |
| Q-04 | **logic ของ Custom Logic** — ผ่าน format แล้วทำอะไร ไม่ผ่านแล้วทำอะไร (คง `batch_out` เดิม / สร้างเลขใหม่ / error) และ "Incoming Batch Number" คือ `batch_in` ใช่หรือไม่ | ผู้ใช้ + ฟังก์ชันนอล | ⬜ |
| Q-05 | **type ของ parameter** — ใช้ data element `CHARG_D` (ถ้า released) หรือ `c LENGTH 10` | Claude เช็คบน ADT ร่วมกับผู้ใช้ | ⬜ |
